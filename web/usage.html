仅统计本机已写出用量的请求，不代表全部请求或全部失败请求。账号由本机运行进程核对：启用观察后，实际观察到的新写入用量才可归属。旧历史无法反推，缺证或存在冲突的请求保留“未归属”，不会分摊给任何账号。账号汇总跟随时间与模型，保留全部账号用于比较。

输入 Token 已包含缓存命中；“新增输入”扣除缓存读取与缓存写入。推理 Token 已包含在输出中，均不重复叠加。缓存命中率为缓存读取 ÷ 全部输入，零输入时显示未知。缓存写入与各项原始计数可点行查看。

速度为包含等待时间的日志估算，不等于模型纯生成速度。GPT 参考成本默认按 OpenAI Standard API 美元参考价估算，已核 2026-11-09；有长上下文价时按每次输入量自动切换。缓存写入以 30m 价格参考，不含 Fast、区域及工具费用；手动价以设置为准。AGY 按对应 API 模型参考价（Google / Anthropic 官方价），别名按对应 API 模型估算；缓存与长上下文按各供应商规则，缺价保留未定价；合并金额仅含已定价部分。不是订阅扣款或实际账单；未设置价格显示“未定价”，部分定价仅汇总已定价部分。
